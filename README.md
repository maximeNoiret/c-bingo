## Installing
### Windows - [Releases][releases-link]
If you're on Windows, you can use the pre-compiled binary in the [releases][releases-link] page.
### Linux - Building from Source
If you're on Linux, you know how to enter a command in the terminal.
To compile the project:
```
git clone https://git.purparmalm.com/maximeNoiret/c-bingo
cd c-bingo
make
```
The executable will be in the `build` folder.
You can also install it on your system... if for some reason you want that.
```
sudo make install
```
And once you realize it's pointless to install it because, at least for now since you need the wordlist.txt file in your current working directory, you can uninstall it with this.
```
sudo make uninstall
```
